# JavaScript Task 1

## Description

This project is a simple JavaScript application that demonstrates the use of basic JavaScript concepts.

## Concepts Used

* Variables
* User Input
* Output
* Comparison Operators
* Conditions
* Logical Operators

## Project Features

* Takes information from the user using `prompt()`.
* Uses variables to store the entered data.
* Uses conditions to determine the appropriate result.
* Checks whether the selected order is available.
* Displays the result to the user.
